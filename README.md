# Secure-Bank-Management-System


A full-stack banking prototype with a **Java console backend** and a **responsive web frontend**.

---

## ✨ Features
- **Customer Management** – Register customers with validation for age, phone, and email.
- **Account Operations** – Open Savings, Current, Fixed Deposit, and Recurring Deposit accounts with dynamic interest rates and maturity dates.
- **Transactions** – Deposit, Withdrawal, and Transfer with real-time balance updates and transaction history.
- **Loan Module** – Apply for Personal, Home, Car, or Education loans; automatic EMI calculation.
- **Interactive Web UI** – Built using HTML, CSS, Bootstrap, and Vanilla JS for smooth navigation and record display.

## 🛠️ Tech Stack

- **Backend** - Java, OOP principles, Collections Framework
- **Frontend** - HTML5, CSS3, Bootstrap 5, JavaScript 
- **Utilities** - Font Awesome Icons

## 🔮 Future Enhancements

- REST API with Spring Boot to connect the web interface to the Java backend.
- Database integration (MySQL/PostgreSQL) for persistent storage.
- User authentication and role-based access control.
- Dockerized deployment for cloud hosting.
